# 数据处理说明（技术事实，非已发布隐私政策）

- 插件在本机读取当前 Codex 非归档、非子代理会话与正式项目归属。项目归属依赖本地 Codex 配置格式，无法识别时归入未归类。不会根据目录猜测项目。
- 日常浏览、搜索、读取缓存与识别会话文件不调用模型。文件列表仅从成功的文件变更与可识别的直接写入记录提取，不遍历磁盘补猜；单纯阅读、回复链接不算产出，链接仅为已验证产出补充说明。动态路径和脚本间接产物无法确认时不展示。
- 点击摘要生成/更新或首次「生成并体验」才授权向当前 Codex 登录所使用的 OpenAI 模型发送消息摘录。会话摘要取最初2轮及最近8轮；项目概况取最近最多20个会话，每个最初1轮与最近2轮，含标题。工具输出及项目文件不发送；用户/助手消息本身可能含代码或敏感内容，应确认适合发送。
- 生成通过本机 `codex exec` 完成，使用账号额度。远端处理及保留规则受所用 OpenAI 服务及账号设置影响，本插件不能承诺远端零保留或删除。
- 摘要、来源标识及时间保存在本地插件数据目录；语言/引导选择保存在 onboarding.json。缓存不因过期自动删除，旧结果保留供阅读。生成失败临时目录会清理；进程异常中断可能残留操作系统临时文件。
- 文件预览绑定 127.0.0.1，并使用不可猜的路径令牌与文件归属校验；不能据此当作跨机器文件服务。HTML 产出内容可自带外部资源或脚本，浏览器打开后可能发起网络请求；插件自带预览依赖在本地，不代表用户文件不会联网。
- 插件当前没有自建分析统计、广告或独立后台服务。本地缓存是普通文件，不额外加密，仍需依赖设备权限与磁盘保护。
- 删除插件不等于删除摘要缓存；清理方式见 INSTALL.md。删除本地缓存不会撤回已发送至模型的消息。

公开政策仍需发布者确认身份、联系方式及适用政策，再发布到真实可访问地址。本说明不能充当已经发布或审定的隐私政策。
